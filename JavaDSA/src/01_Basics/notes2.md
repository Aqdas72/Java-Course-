user → user code → Compiler(javac) → bytecode → JVM → machine Understandable code → JVM → Run the code in your pc


* bytecode → platform independent means we can use that bytecode in any OS
like windows, Linux, Mac using JVM

* What is JVM??
Java Virtual machine its change bytecode to machine Understandable code
and execute/run the code in your computer

* What is JIT??
just in time - its help to execute bytecode faster into machine level language
byte code -> JVM -> JIT compiler -> Machine level language


* What is JRE ??

JRE = JVM + Java Libraries

* What is JDK??

JDK = JRE (JVM + Java Libraries) + Development Kit(java , javac, decoder)
